# 🏡 Family Hub — прототип

Игровое семейное пространство: квесты, экономика **«Сердечек» (♥)**, Магазин привилегий, лидерборд-гонка, ранги и достижения. Ролевая модель (Админ / Родитель / Подросток / Ребёнок) меняет интерфейс.

Это **клиентский прототип** для тестирования концепции в VK. Бэкенда нет — данные хранятся в браузере (`localStorage`), поэтому он деплоится как обычный статический сайт и открывается внутри VK Mini App.

---

## ✨ Что уже работает

- **Дашборд** — приветствие, погодный виджет, таймер до отпуска, «Гонка недели» (лидерборд), рейд-босс, превью квестов и фото.
- **Квесты** — отметка выполнения с конфетти, летящими ♥, звуком монетки и начислением в копилку/XP. Стрик ≥ 7 дней даёт ×2.
- **Магазин привилегий** — покупка с подтверждением и списанием ♥. «Взрослый» раздел скрыт для детской роли.
- **Семья** — участники, роли, уровни, семейное древо.
- **Профиль** — аватар, ранг, XP-бар, статистика, достижения, сброс демо.
- **Ранги** — Зайчонок → Бельчонок → Хранитель Очага → Легенда Семьи (каждые 300 XP), с золотой вспышкой «Новый ранг».
- **VK Bridge** — при запуске внутри VK подтягивает имя и аватар пользователя и тему (светлая/тёмная). Вне VK всё работает автономно.
- Тёмная тема, звук (вкл/выкл), онбординг из 3 экранов при первом запуске.

> Смена участника — тап по аватару справа вверху. Так видно, как интерфейс меняется по ролям.

## 🌐 Шаг 2. Задеплоить на Render

**Вариант А — через Blueprint (проще):**
1. [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint**.
2. Подключите GitHub и выберите репозиторий `family-hub`. Render прочитает `render.yaml` и создаст статический сайт.
3. Нажмите **Apply** и дождитесь окончания деплоя.

**Вариант Б — вручную:**
1. **New** → **Static Site** → выберите репозиторий.
2. Заполните поля:
   - **Build Command:** оставьте пустым (или `echo ok`).
   - **Publish Directory:** `.`
3. **Create Static Site**.

После деплоя Render выдаст адрес вида `https://family-hub-xxxx.onrender.com` — **скопируйте его**. Откройте его в браузере: прототип должен работать сразу (в автономном режиме, без данных VK).

> Статические сайты на Render раздаются по HTTPS и бесплатны — это всё, что нужно VK.

---

## 📱 Шаг 3. Подключить как VK Mini App

1. Откройте [vk.com/apps?act=manage](https://vk.com/apps?act=manage) → **Создать приложение** → тип **VK Mini App (Веб)**.
2. В настройках приложения найдите раздел **«Размещение»** (Hosting).
3. В подразделах **«Мобильные устройства»** и **«Веб»** укажите ваш Render-URL (например `https://family-hub-xxxx.onrender.com/`).
4. В подразделе **«Состояние»** выберите **«Приложение включено»** и сохраните.
5. Откройте приложение по ссылке `https://vk.com/app<ID>`, где `<ID>` — идентификатор из настроек.

**Для приватного теста без публикации:** используйте раздел **«Тестирование»** — создайте группу тестировщиков и вставьте туда тот же URL. Приложение увидят только приглашённые.

> Если внутри VK всё «серое»/не загружается — почти всегда это HTTP вместо HTTPS или неверный URL в «Размещении». Render-адрес уже на HTTPS, так что просто вставьте его целиком, со слэшем на конце.

## 🔧 Локальный запуск (для правок)

Из-за путей к `src/*.js` открывать `index.html` двойным кликом не стоит — поднимите локальный сервер:

```bash
# Python
python3 -m http.server 5173
# или Node
npx serve .
```

Затем откройте `http://localhost:5173`.
