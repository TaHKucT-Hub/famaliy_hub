# 🏡 Family Hub

Игровое семейное пространство: квесты, экономика **«Сердечек» (♥)**, Магазин привилегий, лидерборд-гонка, ранги и достижения, лента новостей, чат и админ-панель. Ролевая модель (Админ / Родитель / Подросток / Ребёнок) меняет интерфейс.

Это **полноценное приложение с бэкендом**, готовое к бета-тесту в VK Mini App: реальные семьи с общими данными, живая синхронизация между устройствами (WebSocket), загрузка фото и документов, авторизация через VK.

---

## ✨ Что уже работает

- **Дашборд** — приветствие, «Гонка недели» (лидерборд по ♥), превью твоих квестов.
- **Лента + Чат** — семейная стена (посты, фото, лайки, комментарии) и групповой чат с фото-вложениями. Обновляются в реальном времени у всех участников.
- **Квесты/Задачи** — отметка выполнения с конфетти, летящими ♥ и звуком. Стрик ≥ 7 дней даёт ×2. Есть сроки, повторяющиеся задачи (ежедневно/еженедельно), фото-подтверждение выполнения и личный быстрый TODO.
- **Магазин привилегий** — покупка с подтверждением и списанием ♥, каталог настраивается админом.
- **Семья** — участники, роли, уровни, код приглашения, документы семьи (загрузка любых файлов).
- **Профиль** — загрузка своего фото-аватара, ранг, XP-бар, статистика, достижения.
- **Админка** (⚙️, видна только роли «Админ»): управление участниками и ролями, редактирование квестов и магазина, модерация ленты/чата, статистика семьи.
- **Ранги** — Зайчонок → Бельчонок → Хранитель Очага → Легенда Семьи (каждые 300 XP).
- **VK Bridge** — при запуске внутри VK подтягивает имя, аватар и тему пользователя. Вне VK работает в dev-режиме (см. ниже).

## 🏗️ Архитектура

```
famaliy_hub/
├── index.html, styles.css, src/*.js   # фронтенд: чистый HTML/CSS/JS, без сборки
│   ├── state.js   # in-memory состояние + локальные UI-настройки (тема/звук)
│   ├── api.js      # REST-клиент к бэкенду
│   ├── ws.js       # WebSocket-клиент (живая синхронизация)
│   ├── vk.js       # интеграция VK Bridge (с таймаутами и dev-фолбэком)
│   ├── render.js   # рендер экранов
│   └── app.js      # авторизация, роутинг вкладок, обработка событий
├── backend/
│   ├── requirements.txt
│   └── app/
│       ├── main.py        # FastAPI-приложение, отдаёт и API, и фронтенд
│       ├── models.py       # SQLAlchemy: Family, User, Membership, Task, ShopItem, Post, ChatMessage, FileAsset…
│       ├── security.py     # проверка подписи VK launch-параметров + JWT-сессии
│       ├── ws.py           # менеджер WebSocket-комнат по семьям
│       └── routers/        # auth, family, tasks, shop, feed, chat, files, admin, profile
├── render.yaml   # Blueprint: веб-сервис (Python) + Postgres
└── .gitignore
```

**Как это работает:** один и тот же веб-сервис (FastAPI) отдаёт и API (`/api/*`), и статические файлы фронтенда — поэтому не нужен отдельный CORS/деплой для UI. Каждая семья — это своя «комната»: при любом изменении (новая задача, лайк, сообщение) сервер рассылает всем подключённым участникам семьи короткий WebSocket-пинг, а клиент дозапрашивает изменившийся кусок данных. Фото и документы хранятся прямо в Postgres (без отдельного S3) — этого достаточно для бета-теста.

## 🔑 Авторизация и роли

1. Пользователь открывает Mini App → фронтенд получает `vk_user_id`/`sign` из launch-параметров и профиль через VK Bridge.
2. Бэкенд проверяет подпись VK (HMAC по `VK_APP_SECRET`) и выдаёт JWT-сессию.
3. Если человек ещё не в семье — экран **«Создать семью» / «Присоединиться по коду»**. Создатель семьи автоматически становится **Админом**.
4. Админ в разделе **⚙️ Админка** назначает роли остальным участникам (Родитель/Подросток/Ребёнок), правит возраст, аватар-эмодзи, цвет, сердечки/XP.

**Dev-режим:** если переменная окружения `VK_APP_SECRET` не задана, сервер не проверяет подпись VK и принимает любой `vk_user_id` — это нужно для локальной разработки и тестирования вне VK. Перед реальным запуском в VK обязательно задайте `VK_APP_SECRET` (см. деплой ниже) — иначе сессию сможет подделать кто угодно.

## 🚀 Деплой на Render

### Шаг 1 — залить на GitHub

```bash
cd famaliy_hub
git add .
git commit -m "Family Hub: backend + real-time sync"
git push
```

### Шаг 2 — создать сервисы на Render

1. [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint**.
2. Подключите репозиторий — Render прочитает `render.yaml` и создаст:
   - **Postgres** (`familyhub-db`, бесплатный тариф);
   - **Web Service** (`family-hub`, Python/FastAPI) с `DATABASE_URL` и сгенерированным `JWT_SECRET`.
3. Нажмите **Apply** и дождитесь деплоя (первый билд ставит зависимости из `backend/requirements.txt`).
4. В настройках сервиса **family-hub → Environment** добавьте переменную **`VK_APP_SECRET`** — это **«Защищённый ключ»** (Secure key) вашего приложения из настроек VK (см. шаг 3), не «сервисный ключ доступа».

После деплоя Render выдаст адрес вида `https://family-hub-xxxx.onrender.com` — откройте его в браузере: должен появиться экран «Создать семью / Присоединиться».

> ⚠️ Бесплатный план Postgres на Render **удаляется через 90 дней** — для реального бета-теста этого достаточно, но для долгосрочной эксплуатации нужен платный план.
> ⚠️ Бесплатный веб-сервис «засыпает» после ~15 минут простоя и просыпается ~30–50 секунд на первый запрос — это нормально для беты.

### Шаг 3 — подключить как VK Mini App

1. [vk.com/apps?act=manage](https://vk.com/apps?act=manage) → **Создать приложение** → тип **VK Mini App (Веб)**.
2. Скопируйте **«Защищённый ключ»** (Secure key) из настроек приложения и вставьте его в переменную `VK_APP_SECRET` на Render (шаг 2.4), затем передеплойте сервис (Manual Deploy).
3. В разделе **«Размещение»** (Hosting) в подразделах **«Мобильные устройства»** и **«Веб»** укажите ваш Render-URL, например `https://family-hub-xxxx.onrender.com/`.
4. В разделе **«Состояние»** выберите **«Приложение включено»** и сохраните.
5. **Для приватного бета-теста** — раздел **«Тестирование»**: создайте группу тестировщиков и добавьте туда всех членов семьи по их VK-аккаунтам. Каждый откроет приложение по ссылке `https://vk.com/app<ID>` на своём телефоне.

Первый, кто откроет приложение, создаёт семью и получает код приглашения (виден на вкладке «Семья» — кнопка «копировать»). Остальные вводят этот код на экране входа, чтобы попасть в ту же семью.

## 🔧 Локальный запуск (для разработки)

Нужен только Python 3.11+ (зависимости — в `backend/requirements.txt`):

```bash
cd famaliy_hub
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload --port 8000
```

Откройте `http://localhost:8000` — FastAPI сам отдаёт и API, и фронтенд (никакого отдельного `http.server` не нужно). Без `VK_APP_SECRET` в окружении сервер работает в dev-режиме: можно тестировать, добавив к адресу `?vk_user_id=1` (у каждого числа — свой «пользователь»), либо просто открыв без параметров (тогда все сессии сведутся к одному гостевому аккаунту в одной вкладке — чтобы проверить многопользовательский сценарий, открывайте разные `vk_user_id` в разных вкладках/профилях браузера).

Локально данные пишутся в SQLite (`backend/familyhub.db`, в `.gitignore`) — файл можно удалить, чтобы начать с чистого состояния.
